# dsh-done-pill — 对话完成胶囊（消息胶囊）

从 dsh-webui 的 `done-pill` 模块拆出的**独立插件**：任一会话（含后台
会话）回合完成时提醒、点击跳会话、悬停看记录全文，附带健康提醒
（休息时段 / 凌晨提醒）与胶囊外观设置（大小 / 字体）。
**全程零 DSH 源码改动。**

> v0.7.0（两种形态）：设置里新增「胶囊形态」（卡片 / 悬浮，二选一，
>  localStorage `dsh.donePill.mode` 持久化，默认卡片）——
>  **卡片**：左下角设置上方的小横条（`sidebar.footer.action` 槽位，
>  天然排在设置行上方），摘要展示进行中/完成数，鼠标悬停（触屏点按）
>  后在卡片上方弹出「进行中 + 最近完成」面板；侧边栏收起成 56px rail
>  时退化为带数标徽的图标钮，弹窗逻辑不变。**悬浮**：原来的顶部可拖拽
>  浮窗（`shell.overlay`）。缩放 / 字体 / 总显隐三套设置两种形态共用，
>  已读态同键共享，切换形态即时生效（含 HMR 热更）。
>
> > v0.7.1（置顶修正）：dsh-mobile-plus 会把宽栏底部并成一行（设置左、
> > 动作右），卡片曾被挤到设置右边。本版加了一段 `:has()` 双锁的注入式
> > CSS（只在宽栏 + 卡片挂载时生效）：动作组独占一行顶到设置行上方，
> > 设置行回到独占一行；切悬浮后自动失效，不动任何源码、与其他插件共存。
> >
> > v0.7.2（图标归位）：v0.7.1 把手机配对等动作图标也一起顶了上去。本版把
> > footerActions 及其槽位出口透明化（`display:contents`），只让卡片独占首行，
> > 其他图标 `order:1` 留在末行设置右侧原位。
> >
> > v0.7.3（顺序修正）：v0.7.2 点名图标的 `order` 规则没打中手机图标
> > （跑到设置左边去了）。改由设置区自己 `order:-1`（与卡片同级，靠 DOM
> > 先后决出卡片首行、设置末行首位），图标不再逐个点名，默认就排在设置
> > 右边，新增动作图标也自动归位。

> 背景：dsh-webui（全家桶）已于 2026-08-28 卸载，其 done-pill 能力随之下线。
> 本插件把该模块原样移植为单体插件，行为与数据契约不变，方便只想要「消息
> 胶囊」的用户。

> v0.6.5（壳子顶栏热区让位）：修复「胶囊停靠顶栏时上半段点不到」——电子壳子
> 顶部中间的隐形拖拽带（#drag-strip，300×28，app-region:drag）压住了胶囊。
> 插件 client 半身跟踪胶囊矩形与光标，POST 到 host 新增的
> `POST /api/dsh-done-pill/shell-hot`，host 经壳子 CDP（`D:/AI/Dsh/.shell-cdp-port`）
> 给壳页面注入幂等补丁：光标悬停胶囊上时给 #drag-strip 挂 `.dsh-pill-hot`
> （pointer-events:none + no-drag），拖拽带整体让位给 WebUI，胶囊点击/悬停/
> 面板滑出恢复正常；光标离开胶囊自动恢复拖拽。纯插件实现：不改壳子文件、
> 不碰 DSH 源码；壳子未运行（纯浏览器访问 WebUI）或老版本壳子（无
> #drag-strip）自动降级，仅顶部中段失去拖拽热区（拖窗口可拖页面其余留白）。
> 壳子源码 .shell-src/topbar.css 已同步该样式（canonical），下次打包 asar 直接带上。
